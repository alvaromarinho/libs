ng-bs-toast-service

Serviço de notificações toast para Angular + Bootstrap 5, com ícones do Bootstrap Icons. Assim como o modal, basta montar <ng-bs-toast-service /> uma vez na raiz da aplicação e chamar toastService.send(...) de qualquer componente ou serviço.

8 cores do Bootstrap 2 temas (bootstrap / bootstrap-dark) 7 posições Barra de progresso, pausa no hover Duração por estilo (warning 7s, danger 10s, resto 4s) Fila com limite por posição dismiss(id) / dismissAll()
Código
Instalação (app.component.html): 
<ng-bs-toast-service [maxToastsPerPosition]="5" />
Typescript: 
toastService = inject(NgBsToastService);

send(style: ToastStyle) {
    // duration omitido: resolvido pelo style (warning 7s, danger 10s, resto 4s)
    this.toastService.send('Título', 'Mensagem', style, undefined, {
        theme: 'bootstrap-dark', // 'bootstrap' | 'bootstrap-dark'
        position: 'bottom-end'   // top/middle/bottom x start/center/end
    }).subscribe(() => console.log('toast fechado'));
}
Template: 
<button (click)="send('success')">Success</button>
Fechar programaticamente: 
this.toastService.dismiss(id);   // um toast específico
this.toastService.dismissAll();  // todos, mostrados ou na fila
