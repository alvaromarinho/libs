ng-bs-toast-service

Serviço de notificações toast para Angular + Bootstrap 5, com ícones do Bootstrap Icons. Assim como o modal, basta montar <ng-bs-toast-service /> uma vez na raiz da aplicação e chamar toastService.send(...) de qualquer componente ou serviço.

4 estilos (success/warning/danger/primary) Fila de notificações Fechamento automático Título opcional sem mensagem
Código
Instalação (app.component.html): 
<ng-bs-toast-service />
Typescript: 
toastService = inject(NgBsToastService);

send(style: string) {
    this.toastService.send('Título', 'Mensagem', style);
}
Template: 
<button (click)="send('primary')">Primary</button>
 @if (lastSent()) {
Último enviado: estilo {{ lastSent() }}
}
