ng-month-year-picker

Dropdown seletor de mês/ano para Angular. O valor é sempre uma string no formato YYYY-MM, o componente emite valueChange e o consumidor decide se atualiza (ou não) o valor exibido.

Valor em formato YYYY-MM Navegação entre anos Nomes de mês customizáveis Fecha ao clicar fora Sem Bootstrap nem ícones externos Tema via CSS custom properties
Código 
<ng-month-year-picker [value]="month()" (valueChange)="month.set($event)"></ng-month-year-picker>
Demo
Valor selecionado: {{ month() }} — use os botões / no cabeçalho do dropdown para navegar entre anos sem alterar o valor.
