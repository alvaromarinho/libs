ng-bs-modal-service

Serviço de modais para Angular + Bootstrap 5. Em vez de declarar um <div class="modal"> para cada caso de uso, você injeta NgBsModalService e chama open() de qualquer lugar da aplicação — o componente <ng-bs-modal-service />, montado uma única vez na raiz, cuida de renderizar o conteúdo.

Fila de modais Carrossel de imagens Modo popover Backdrop estático Tamanhos sm/lg/xl Classes customizadas
Código
Instalação (app.component.html): 
<ng-bs-modal-service />
Typescript: 
modalService = inject(NgBsModalService);

showModal(body: TemplateRef<any>) {
    this.modalService.open({ header: 'Modal', body });
}
Template: 
<button (click)="showModal(modalBody)">Show Modal</button>

Modos de abertura

Popover abre o modal ancorado ao botão clicado (popoverTo). Modal A abre um modal de fila simples — veja abaixo. Modal Content usa um <ng-template> completo, com header/body/footer próprios.

Comportamento de fila

Abra o Modal A e, dentro dele, clique em "Abrir Modal B (sobre A)". O B é exibido sobre o A; ao fechar o B, o A reaparece automaticamente — o NgBsModalService mantém os modais em fila e mostra o próximo quando o atual é fechado.
