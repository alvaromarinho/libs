ng-bs-calendar

Componente de calendário semanal para Angular + Bootstrap 5, com suporte a agendamento via dayjs. Cada evento é posicionado em slots de 30 minutos e eventos sobrepostos no mesmo dia são organizados lado a lado automaticamente.

Visão semanal Slots de 30 minutos Navegação entre semanas Cores por evento Clique em células/eventos Clique em célula vazia Visão diária (mobile) Eventos sobrepostos Standalone ou NgModule Internacionalização Range de horário (startHour/endHour) Slot configurável (slotMinutes) Horário bloqueado (breakHours)
Código
Typescript: 
calendar = [
    { id: 1, title: '1', color: '#ff0000', start: '{{ now }}T19:00:00', end: '{{ now }}T20:00:00' },
    ...
]
Template: 
<ng-bs-calendar [data]="calendar" [view]="isMobile() ? 'day' : 'week'" [startHour]="'08:00'" [endHour]="'17:00'" [slotMinutes]="60" [breakHours]="[{ start: '12:00', end: '13:00' }]" (changeWeek)="onEvent($event)" (clickCell)="onEvent($event)" (clickEmptyCell)="onEvent($event)"></ng-bs-calendar>
