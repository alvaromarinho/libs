ng-generate-table

Gerador de tabelas dinâmicas para Angular a partir de uma configuração de colunas: aplique pipes do Angular, renderize HTML customizado por célula, ative ordenação, visão em cards para mobile e linhas expansíveis — sem escrever <table> manualmente. As abas abaixo cobrem cada um desses recursos com um exemplo independente.

Configuração via columns Pipes e templates customizados Ordenação por coluna Linhas e células clicáveis Visão em cards (mobile) Linhas expansíveis Estados de loading/vazio thead/tbody/tfoot customizados
Código 
columns: NgGenerateTableColumns[] = [
    { label: 'Name',  field: 'name',  sortable: true },
    { label: 'Email', field: 'email' },
    { label: 'Data',  field: 'date' },
];
<ng-generate-table [columns]="columns" [data]="data" tableClass="table table-sm table-bordered"></ng-generate-table>
