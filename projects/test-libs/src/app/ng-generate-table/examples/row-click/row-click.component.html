Com [rowClickable]="true", a tabela passa a destacar a linha sob o cursor (table-hover) e emite rowClick com a linha clicada e o evento original — ideal para abrir um detalhe ou navegar para outra página.

@if (lastRow()) {
Linha clicada: {{ lastRow().name }} — {{ lastRow().email }}
}
Código
Typescript: 
lastRow = signal<any>(null);

onRowClick($event: { row: any, event: Event }) {
    this.lastRow.set($event.row);
}
Template: 
<ng-generate-table
    [columns]="columns" [data]="data"
    [rowClickable]="true"
    (rowClick)="onRowClick($event)"
    tableClass="table table-sm table-bordered table-hover">
</ng-generate-table>
