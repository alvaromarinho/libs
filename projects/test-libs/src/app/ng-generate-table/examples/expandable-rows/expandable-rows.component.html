Quando o #rowDetail é projetado, a primeira coluna ganha automaticamente um botão de toggle. O estado fica em expandedRows, controlado pelo consumidor via [(expandedRows)]. Ao expandir, o conteúdo do #rowDetail aparece abaixo da linha. Use expandableRow para decidir quais linhas podem ser expandidas — neste exemplo, apenas os pedidos do Marinho e do Álvaro têm o toggle.

Código
Typescript: 
columns: NgGenerateTableColumns[] = [
    { label: 'Cliente', field: 'customer' },
    { label: 'Total', field: 'total' },
];

// Controla quais linhas estão expandidas
expandedRows = new Set<any>([this.orders.find(o => o.customer === 'Marinho')?.id]);

// Apenas linhas para as quais essa função retorna true terão o toggle de expand
expandableRow = (order: any) => order.customer === 'Marinho' || order.customer === 'Álvaro';
