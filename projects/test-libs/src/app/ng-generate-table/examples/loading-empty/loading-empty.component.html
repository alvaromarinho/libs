[loading]="true" exibe a loadingMessage configurada em config no lugar das linhas. Quando [data] é um array vazio, a tabela exibe a emptyMessage — use os botões abaixo para alternar entre os dois estados.

Código
Typescript: 
loading = signal(false);
hasData = signal(true);
Template: 
<ng-generate-table
    [columns]="columns"
    [data]="hasData() ? data : []"
    [loading]="loading()"
    [config]="{ emptyMessage: 'Nenhum registro encontrado.', loadingMessage: 'Aguarde...' }"
    tableClass="table table-sm table-bordered">
</ng-generate-table>
