ng-bs-pagination

Componente de paginação configurável para Angular + Bootstrap 5. A propriedade current é sempre de mão única — o componente nunca a altera diretamente, apenas emite change, first e last para que o consumidor atualize o estado.

Layouts split/center/stacked Janela de páginas configurável Botões primeira/última Tamanhos sm/md/lg Texto de info customizável Navegação por texto ou ícone
Código 
<ng-bs-pagination
    [total]="124" [current]="current()" [itemPerPage]="10"
    (change)="current.set($event)" (first)="current.set($event)" (last)="current.set($event)">
</ng-bs-pagination>
