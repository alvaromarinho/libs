ng-dd-file

Componente de upload de arquivos por arrastar-e-soltar (ou seleção manual) para Angular, com validação de tamanho/tipo e preview automático de imagens em base64. O componente não guarda estado próprio — filesList é controlado pelo consumidor via os eventos filesAdd/fileRemove.

Drag & drop + clique Preview de imagens Limite por arquivo e total Filtro por tipo de arquivo Múltiplos arquivos Labels customizáveis (i18n)
Código
Typescript: 
files = signal<File[]>([]);

onFilesAdd(newFiles: File[]) {
    this.files.update(existing => [...existing, ...newFiles]);
}
Template: 
<ng-dd-file
    [btnClass]="{ file: 'btn btn-primary', remove: 'btn btn-sm btn-danger' }"
    [filesList]="files()"
    [maxFiles]="3"
    [maxFileSize]="200"
    [maxTotalSize]="300"
    (fileError)="lastError.set($event.message)"
    (fileRemove)="files.set([])"
    (filesAdd)="onFilesAdd($event)"
/>
Demo

Limite configurado neste exemplo: máximo de 3 arquivos, 200 KB por arquivo e 300 KB no total — exceder qualquer um dispara o evento fileError.
