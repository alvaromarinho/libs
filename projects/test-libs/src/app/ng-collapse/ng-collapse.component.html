ng-collapse

Wrapper de collapse/expand suave para Angular, animado via transições CSS de max-height — sem dependência do Bootstrap ou de qualquer outra biblioteca. Basta envolver o conteúdo com <ng-collapse [toggle]="..."> e controlar o estado com um boolean.

API com um único input Animação suave via CSS Duração configurável Sem dependências externas
Código 
<button (click)="toggle.set(!toggle())">Collapse</button>

<ng-collapse [toggle]="toggle()" [transitionDuration]="500">
    <div class="card card-body">...</div>
</ng-collapse>
Toggle e duração

transitionDuration (em ms) controla o tempo da animação de expansão — experimente mudar o valor e clicar no botão novamente.
